# 智慧長期照護 Web App - 前端原型從零開始架設指南

這是一個結合 LLM 概念的智慧長期照護 Web App 前端原型，使用 Vite + React + Tailwind CSS 打造。本專案完全為前端展示（Mock 狀態），不需連接後端伺服器或資料庫即可在任何電腦上本地運行。

為了讓非工程師或任何從未寫過程式的人也能輕鬆架設，以下為 **Mac** 與 **Windows** 雙系統適用的「從 0 開始」圖文式傻瓜架設教學。

---

## 第一階段：環境準備 (安裝 Node.js)
要讓這個網頁程式跑起來，您的電腦需要一個名為 **Node.js** 的運行環境。

### 🍎 Mac 使用者安裝步驟：
1. 前往 Node.js 官方網站：[https://nodejs.org/](https://nodejs.org/)
2. 點擊下載標示為 **「LTS (Long Term Support)」** 的版本 (這會下載一個 `.pkg` 檔案)。
3. 雙擊下載的 `.pkg` 檔案，一路點選「繼續 (Continue)」、「同意 (Agree)」直到安裝完成。

### 🪟 Windows 使用者安裝步驟：
1. 前往 Node.js 官方網站：[https://nodejs.org/](https://nodejs.org/)
2. 點擊下載標示為 **「LTS (Long Term Support)」** 的版本 (這會下載一個 `.msi` 檔案)。
3. 雙擊執行下載的 `.msi` 檔案，不斷點擊「Next」進行安裝。
   - ⚠️ **重要提示**：在安裝過程中，請確定全部保持預設勾選，特別是 **「Add to PATH」** 這個選項必須勾選 (預設通常已勾)。

---

## 第二階段：開啟命令列 (終端機)
安裝完 Node.js 後，我們需要打開電腦的「命令列」來下達啟動指令。

### 🍎 Mac 使用者：
1. 點擊鍵盤上的 `Command (⌘) + 空白鍵` 打開 Spotlight 搜尋。
2. 搜尋 **「終端機」** 或 **「Terminal」** 並打開它。這會跳出一個黑底或白底的輸入視窗。

### 🪟 Windows 使用者：
1. 點擊左下角「開始」按鈕（或是按鍵盤的 Windows 鍵）。
2. 輸入 **「cmd」**，系統會搜尋出 **「命令提示字元 (Command Prompt)」**，請點擊開啟它。
   - *(另外，您也可以輸入「PowerShell」來使用 Windows PowerShell，效果是一樣的)*

---

## 第三階段：進入專案資料夾並啟動

接下來，我們要告訴系統剛剛下載的專案資料夾在哪裡，並安裝需要的零件。

### 步驟 1：進入資料夾 (`cd` 指令)
在剛剛打開的命令列視窗中，輸入小寫的 `cd`，然後**空一格**。
接下來有一個超簡單的技巧：
👉 **請直接用滑鼠將您的「黑客松比賽前端」這個專案資料夾，拖曳到命令列視窗裡面！**
系統會自動幫您填入資料夾的正確路徑。

整行看起來大概會像這樣：
- Mac: `cd /Users/您的名字/Downloads/黑客松比賽前端`
- Windows: `cd C:\Users\您的名字\Downloads\黑客松比賽前端`

確認無誤後，按下 **Enter 鍵** 執行。

### 步驟 2：安裝相依套件 (`npm install`)
請在命令列輸入以下指令並按下 Enter：
```bash
npm install
```
這時畫面上會開始跑一些進度條，這是系統正在幫您下載這個網頁需要的所有積木套件。請耐心等待它跑完（大約需要數十秒到幾分鐘）。

### 步驟 3：啟動伺服器 (`npm run dev`)
安裝完成後，輸入以下啟動指令並按下 Enter：
```bash
npm run dev
```
此時，您會看到命令列出現綠色的 `VITE` 字樣，並顯示一段網址：
`➜  Local:   http://localhost:5173/`

🎉 **恭喜您！您的本地伺服器已經成功啟動了！**
請不要關閉這個黑色視窗，直接打開您的瀏覽器 (Chrome / Edge / Safari 等)，將 `http://localhost:5173/` 貼上網址列，您就能看到做好的 APP 了！

*(要關閉伺服器時，只要在命令列視窗按下 `Ctrl + C` 即可)*

## 第四階段：系統操作與展示指南

為了讓您能完整體驗所有功能，請依照以下步驟進行測試與展示：

### 【場景一：長輩介面與資料總覽】
1. **註冊/登入**：在首頁的帳號欄位，輸入預設測試帳號：`elder1`，點選 **「長輩本人」** 角色。
2. **AI 小安助手**：登入後，展示專為長輩設計的大字體、極簡操作介面。
3. **查看個人資料**：點擊左下角的 **「系統設定」** (齒輪圖示) -> **「查看個人資料」**。
   - 這裡實作了 AI 互動摘要轉換成的**「記憶卡片」**，展示平時的健康與生活紀錄。
   - 在頁面下方，您會看到一組 **「家人綁定授權碼 (6碼)」**（例如：123456）。請記下這組號碼。

### 【場景二：照護者介面與雙重綁定流程】
1. **切換身分**：點擊左側「系統設定」-> **「切換照護者角色」**。這時會進入照護者的儀表板。
2. **開始綁定**：點擊畫面中央大大的 **「新增家人」** 按鈕。
3. **雙重驗證**：在彈出的視窗中輸入：
   - 長輩帳號：`elder1`
   - 綁定授權碼：請輸入剛剛在長輩資料頁看到的 6 碼數字。
4. **照護管理區**：綁定成功後，長輩卡片就會出現在儀表板上！點擊卡片即可切換上方標籤查看：
   - **個人資料**：檢視長輩基本資料與記憶卡片。
   - **AI 摘要紀錄**：查看 AI 每日與本週對長輩狀況的總結。
   - **設定提醒**：可開啟/關閉或新增要讓 AI 在對話中主動詢問的關心事項（如：「今天有吃過藥嗎？」）。
