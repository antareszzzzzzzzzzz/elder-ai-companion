# 智慧長照陪伴系統 — 從零開始架設指南

本系統為一套結合 AI 的智慧長期照護 Web App，包含 Flask 後端 + React 前端 + AWS 雲端服務。以下為 **Windows** 與 **Mac** 雙系統適用的完整架設教學，讓任何人都能在本機跑起來。

---

## 第一階段：環境準備

你的電腦需要安裝三樣東西：**Python**、**Node.js**、**AWS CLI**。

### 🐍 安裝 Python

1. 前往 [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. 下載 **3.10 以上版本**（建議 3.11 或 3.12）
3. 安裝時 **務必勾選「Add Python to PATH」**（Windows 安裝畫面最下方的核取方塊）
4. 安裝完成後，打開命令列輸入 `python --version` 確認有出現版本號

### 📦 安裝 Node.js

1. 前往 [https://nodejs.org/](https://nodejs.org/)
2. 下載 **LTS（長期支援）版本**
3. 一路下一步安裝，保持預設即可
4. 安裝完成後，打開命令列輸入 `node --version` 確認有出現版本號

### ☁️ 安裝 AWS CLI

1. 前往 [https://aws.amazon.com/cli/](https://aws.amazon.com/cli/)
2. 下載對應你系統的安裝檔
3. 安裝完成後，打開命令列輸入 `aws --version` 確認
4. 執行 `aws configure`，依序輸入：
   - AWS Access Key ID（向管理者索取）
   - AWS Secret Access Key（向管理者索取）
   - Default region name：`us-east-1`（或你們使用的區域）
   - Default output format：`json`

## 第二階段：取得專案

將整個專案資料夾下載或複製到你的電腦上。專案結構如下：

```
eldercare-ai-app/
├── backend/          ← Python Flask 後端
│   ├── stt_service/  ← 語音辨識獨立服務
│   ├── .env.example  ← 環境變數範本
│   └── ...
├── frontend/         ← React 前端
│   ├── .env.example  ← 環境變數範本
│   └── ...
└── start.bat         ← 一鍵啟動腳本（Windows）
```

## 第三階段：設定環境變數

### 後端環境變數

1. 進入 `eldercare-ai-app/backend/` 資料夾
2. 找到 `.env.example`，複製一份改名為 `.env`
3. 用文字編輯器打開 `.env`，填入以下值（向專案管理者索取）：

```env
# AWS 基本設定
AWS_REGION=us-east-1

# Cognito 設定（登入驗證用）
COGNITO_USER_POOL_ID=us-east-1_XXXXXXXXX
COGNITO_APP_CLIENT_ID=你的client_id
COGNITO_APP_CLIENT_SECRET=你的client_secret（如果有）
COGNITO_DOMAIN=你的domain.auth.us-east-1.amazoncognito.com
COGNITO_REDIRECT_URI=http://localhost:5000/api/auth/callback

# AI 模型設定
BEDROCK_MODEL_ID=amazon.nova-lite-v1:0
BEDROCK_REGION=us-east-1

# DynamoDB 設定
DYNAMODB_REGION=us-east-1

# 前端網址（不要改）
FRONTEND_URL=http://localhost:5173
```

### 前端環境變數

1. 進入 `eldercare-ai-app/frontend/` 資料夾
2. 找到 `.env.example`，複製一份改名為 `.env`
3. 填入以下值：

```env
# 後端 API 位址（不要改）
VITE_API_BASE=http://localhost:5000

# 語音辨識服務位址（不要改）
VITE_STT_WS_URL=ws://localhost:8001/ws/transcribe

# Cognito 設定（跟後端 .env 裡的值一樣）
VITE_COGNITO_DOMAIN=你的domain.auth.us-east-1.amazoncognito.com
VITE_COGNITO_CLIENT_ID=你的client_id
VITE_COGNITO_REDIRECT_URI=http://localhost:5000/api/auth/callback
```

## 第四階段：安裝依賴套件（只需做一次）

### 後端依賴

打開命令列，進入後端資料夾：

```bash
cd eldercare-ai-app/backend
pip install -r requirements.txt
```

等它跑完（約 1-2 分鐘）。

### STT 服務依賴

```bash
cd eldercare-ai-app/backend/stt_service
pip install -r requirements.txt
```

### 前端依賴

```bash
cd eldercare-ai-app/frontend
npm install
```

等它跑完（約 1-3 分鐘，會看到進度條）。

## 第五階段：啟動系統

### 方法一：一鍵啟動（推薦，Windows）

直接雙擊 `eldercare-ai-app/start.bat`。

它會自動：
1. 開啟後端 API 服務（port 5000）
2. 開啟語音辨識服務（port 8001）
3. 開啟前端網頁（port 5173）
4. 自動打開瀏覽器

你會看到跳出 3 個黑色命令視窗（各跑一個服務）+ 瀏覽器自動開啟。

### 方法二：手動啟動（Mac 或需要除錯時）

分別開三個終端機視窗：

**視窗 1 — 後端：**
```bash
cd eldercare-ai-app/backend
python app.py
```
看到 `Running on http://127.0.0.1:5000` 就成功了。

**視窗 2 — STT 服務（可選）：**
```bash
cd eldercare-ai-app/backend/stt_service
python main.py
```

**視窗 3 — 前端：**
```bash
cd eldercare-ai-app/frontend
npm run dev
```
看到 `Local: http://localhost:5173/` 就成功了。

然後打開瀏覽器，進入 `http://localhost:5173/`。

## 第六階段：使用系統

### 登入

1. 打開 `http://localhost:5173/`
2. 點擊「登入系統」→ 會跳到 AWS Cognito 登入頁面
3. 輸入帳號密碼（如果沒有帳號，點「註冊」建立一個）
4. 登入成功後自動跳回系統

### 長輩角色

- 登入後預設為長輩角色
- 第一次使用會看到同意書，按「我同意」即可進入
- 主畫面是 AI 聊天：可以打字或按「按住說話」用語音聊天
- 左側「系統設定」→「查看個人資料」可以填寫慢性病、用藥、綁定碼等
- 個人資料頁面如果有家人要求追蹤，會顯示「追蹤請求」讓你核准

### 照護者角色

- 在「系統設定」→「切換照護者角色」
- 照護者首頁可以綁定家人（需要對方的帳號代碼 + 6碼綁定碼）
- 綁定後需要等長輩在個人資料頁面「核准」
- 核准後即可在照護者首頁看到家人卡片，點入查看：
  - 個人資料與記憶卡片
  - AI 摘要紀錄（可觸發生成每日摘要 / 本週總結）
  - 設定提醒

## 常見問題

**Q: 點登入沒反應 / 跳出空白頁**
→ 檢查前端 `.env` 的 `VITE_COGNITO_DOMAIN` 和 `VITE_COGNITO_CLIENT_ID` 是否正確填入。

**Q: 登入後看到 401 錯誤**
→ 後端的 `.env` 裡 Cognito 設定可能不正確，或 DynamoDB 表還沒建立。

**Q: 語音按鈕按了沒反應**
→ 瀏覽器會要求麥克風權限，請允許。如果 STT 服務沒啟動，會自動 fallback 到瀏覽器內建語音辨識（需要 Chrome）。

**Q: 要怎麼完全停止系統？**
→ 關閉所有命令視窗即可。或在視窗裡按 `Ctrl + C`。

---

## 停止服務

- **Windows**：關閉那三個命令視窗
- **Mac/Linux**：在每個終端機按 `Ctrl + C`
