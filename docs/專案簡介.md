# 智慧長照陪伴系統 — 以 AI 縮短長照資源落差

## 專案概述

本系統為針對臺灣醫療與照護資源匱乏地區所設計的智慧陪伴平台，以「人機協作，生活支持陪伴」為核心精神，運用生成式 AI 技術提供長者日常語音互動、自動化生活記錄、以及照護者遠端監看的完整解決方案。系統透過自然語言對話降低長者使用門檻，讓不熟悉科技的年長者也能透過口語與 AI 助手「小安」進行即時互動，同時自動將對話中的健康資訊結構化，供照護者與家屬即時掌握長者近況。

## 核心模組

### Module A — 語音互動陪伴

- 結合語音辨識（STT）與語音合成（TTS），長者以口語方式與 AI 助手「小安」進行自然對話，無需文字輸入或觸控操作
- 支援中文即時語音對話，採用 WebSocket 串流辨識確保低延遲
- 對話具備情境感知能力：
  - **時間感知**：系統注入當前時間，依早中晚調整問候與話題
  - **記憶感知**：基於長者過往對話累積的「事實卡」記憶系統，AI 能記住用藥習慣、飲食偏好、身體狀況，並在適當時機主動關心
  - **追蹤機制**：標記為 `track: true` 的健康變化，AI 會在後續對話中主動追蹤進展
- AI 回應以長輩友善的口語化語氣生成，避免專業術語，語句簡短自然
- 嚴格禁止編造醫療資訊的安全鐵律寫入 system prompt

### Module B — 生活記錄與智慧摘要

- **雙重 Bedrock 呼叫架構**：
  1. 第一次呼叫：生成自然語言回覆（結合事實卡 + 知識庫 + 個人資料）
  2. 第二次呼叫：分析對話內容，自動提取記憶操作（新增/更新事實卡）
- 自動辨識並分類長者生活資訊：飲食、活動、睡眠、用藥、身體、情緒
- 事實卡更新採交易式寫入，保留修改歷史
- 智慧查重：AI 在新增事實前會比對現有記錄，避免重複
- **每日自動生成結構化摘要**：彙整當日所有事實卡，由 AI 歸納為自然語言段落
- **跨日洞察分析**：分析近 7 天重複出現的模式（如連續多日睡眠不佳），生成趨勢觀察

### Module C — 照護者資訊介面

- 照護者透過綁定機制（帳號代碼 + 6 碼授權碼雙重驗證）連結長者帳號
- 照護者後台提供：
  - **長者基本資料總覽**：顯示名稱、帳號、累計互動次數
  - **AI 生成之每日摘要紀錄**：以時間軸格式呈現，一目了然
  - **記憶卡片總覽**：依類別（用藥/飲食/活動/情緒）分色顯示
  - **跨日洞察**：AI 自動發現的重複行為模式與健康趨勢提醒
- 照護者可即時觸發「產生每日摘要」與「更新跨日洞察」

## 進階模組

### 知識庫建置

- 收錄照護與衛教相關資料至 `HealthKnowledgeBase` 資料表
- 每次對話時自動以關鍵字/正則表達式比對使用者訊息，將命中的衛教知識注入 AI 回應的上下文
- AI 優先參考知識庫內容回答健康問題，避免編造

### 角色化介面設計

- 系統區分「長輩」與「照護者」兩種角色，依角色呈現完全不同的操作介面
- 長輩介面：大字體、極簡操作、語音優先、AI 陪伴對話為主
- 照護者介面：資料密度較高、多 tab 切換、管理導向

---

## 個資保護與安全設計

- 所有 API 請求須攜帶 AWS Cognito 簽發之 JWT，後端逐請求驗證
- 照護者查看長者資料前須通過追蹤關係權限檢查（approved follow）
- 綁定機制採雙重驗證（帳號代碼 + 6 碼授權碼），防止未經授權存取
- 對話紀錄與健康資料存放於 DynamoDB，傳輸層為 HTTPS
- 所有展示資料皆為模擬或去識別化資料，不含真實長者個人資訊
- AI system prompt 嚴格禁止編造醫療資訊，無法確認時引導使用者諮詢專業人員

## 使用者旅程

### 長者端

1. 登入系統（Cognito OAuth2）
2. 進入小安助手對話介面
3. 按住「按住說話」按鈕以口語方式聊天（或打字）
4. AI 即時回應並朗讀（語音合成）
5. 系統自動從對話中提取飲食、用藥、活動等資訊，建立記憶卡片
6. 長者可在個人資料頁查看自己的記憶卡片與綁定授權碼

### 照護者端

1. 登入系統，選擇照護者角色
2. 輸入長輩帳號代碼 + 6 碼綁定授權碼完成綁定
3. 在管理中心查看已綁定的家人列表
4. 點入長輩專屬照護區，切換查看：
   - 個人資料與記憶卡片
   - AI 每日摘要時間軸
   - 主動關懷設定
5. 可即時觸發生成摘要與跨日洞察分析

## AWS 服務使用

| 服務 | 用途 |
|------|------|
| Amazon Bedrock | LLM 對話生成 + 記憶提取 + 摘要生成 + 洞察分析 |
| Amazon Polly | 中文語音合成（Neural Engine, Zhiyu） |
| AWS Transcribe | 即時語音辨識（WebSocket 串流） |
| Amazon DynamoDB | 全部資料儲存（帳號、對話、事實卡、摘要、知識庫） |
| AWS Cognito | 使用者認證與授權（OAuth2 + JWT） |

## 技術亮點

1. **AI 記憶系統**：非簡單對話歷史，而是結構化事實卡 + 追蹤機制 + 歷史保留 + 智慧查重
2. **雙重呼叫架構**：回覆生成與記憶提取分離，確保穩定性與可控性
3. **安全鐵律**：system prompt 層級禁止編造醫療資訊，從架構上防止 AI 幻覺造成健康風險
4. **Graceful Degradation**：STT/TTS 皆有瀏覽器端 fallback，離線或服務異常時仍可使用
5. **使用 Kiro 進行開發與架構設計**
